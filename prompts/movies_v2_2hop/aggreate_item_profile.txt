### Instruction ###
You are a recommendation-system assistant simulating LightGCN-style neighborhood aggregation using natural language. User–item interactions form a graph. Your task is to compute a textual representation of an item node by aggregating information from multiple hops.

The aggregated profile is cosince description of item node include multi-view:
- Item semantic: intrinsic attributes of the target item
- User profile: summarize which kind of movie user like
- Higher-order collaborative view: analyze 2-hop user, summarize which are other users who watched similar movies as the target user.

### Graph Semantics ###
- Item nodes represent movies.
- User nodes represent viewers with thier preferences
- An edge exists if a user watched a movie.

### Input Information ###
You will aggregate information for an target item node using:
- Item semantics (item name and its characteristics)
- Current item node profile
- 1-hop user neighbors (collaborative signals): users who watched this target movie, each user has a short preference description
- 2-hop item neighbors (higher-order collaborative signals): movies frequently watched by users who also watched the target movie, each movie has a short description


### Your Task ###
Analyze the item semantic information with neighborhood information, summarizing to an concise multi level description for tatget item node with following view level:
- Semantic view: Summarize the intrinsic attributes of the target item, use only the target item’s own information
- Collaborative view: analyze 1-hop user and summarizing shared preferences among users who previously watched this movie. Focus on patterns shared by multiple usersm, do NOT mention specific users. If no 1-hop users are provided, leave this field empty
- Higher-order collaborative view: analyze 2-hop item, identifying recurring themes or co-watch patterns across the 2-hop items and summarizing these patterns. Do describe individual items. If no 2-hop items are provided, leave this field empty

### Important Constraints ###
- Ignore rare or unique attributes that appear only once
- Prefer patterns that appear cross multiple neighbors

### Output Format ###
Return a valid JSON object:

{
  SemanticView: intrinsic attributes of the target item
  CollaborativeView: <Concise summary of intrinsic item features>
  HighOrderCFView: <Aggregated patterns from 1-hop users or empty string>
}

Target item name: the name of the movie {{{target_item_name}}}
Target item characteristics: {{{target_item_characteristic}}}
Current item profile: {{{target_item_profile}}}
List of 1-hop users: {{{1hop_user}}}
List of 2-hop movies: {{{2hop_item}}}
